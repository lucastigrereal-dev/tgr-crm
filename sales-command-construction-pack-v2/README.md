# TGR Sales Command Construction Pack V2

Comece por **00_COMECE_AQUI.md**. Para leitura humana, **GUIA_LUCAS.md**. Para construir, **MANUZI_MASTER_PROMPT.md**. Para conferir, **audit/VERIFICATION_REPORT.md**.

Este é um pacote de especificação + contratos + núcleo de regras reutilizável + demo visual local. Não é a aplicação de produção instalada. Não mistura TGR CRM, TGR Consulting e Sales Command.

Os fontes TypeScript/JSON/SQL/Markdown são editáveis. Não há secrets, dados de clientes, binários do TSE ou dependências node_modules incluídas. Referências históricas não ativam políticas produtivas.

> GitHub temporário de handoff: este conteúdo está em branch isolada do repositório `tgr-crm` apenas porque o conector atual não permite criar um novo repositório remoto. O produto continua separado do TGR CRM e deve migrar para `lucastigrereal-dev/tgr-sales-command` quando esse repositório existir.
