# TSE -> TGR Replacement Program

Este diretório é a fonte canônica para a substituição do TSE/TSExplorer pelo ecossistema TGR.

## Documentos

1. [TSE_TGR_PARITY_MATRIX_V1.md](./TSE_TGR_PARITY_MATRIX_V1.md) - capacidade por capacidade, dono, evidência, status e gap.
2. [TSE_TGR_CUTOVER_GATES_V1.md](./TSE_TGR_CUTOVER_GATES_V1.md) - gates objetivos para desligar o TSE.
3. [TSE_TGR_EXECUTION_BACKLOG_V1.md](./TSE_TGR_EXECUTION_BACKLOG_V1.md) - backlog P0/P1/P2 e ordem por wave.

## Regra de autoridade

- **TGR CRM** substitui o TSE como núcleo e fonte canônica de cliente, oportunidade, proposta, contrato, parcela, fração comercial, direito, reserva e distrato.
- **Sales Command** executa captação, recepção, sala, tour, NT e fechamento e envia fatos ao CRM.
- **Relationship** coordena pós-venda, retenção, risco e atendimento.
- **Online Recovery** coordena não compradores e reativação.
- **Financial Layer** aprofunda dinheiro, DRE, orçamento, forecast e leak detection sem tomar ownership de contrato.
- **Portal do Proprietário** é uma interface externa sobre CRM/Relationship, sem criar uma segunda verdade.
